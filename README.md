## Project Name
THE SOVEREIGN BARBER

## Description
The Sovereign Barber is a modern barbershop website that lets customers learn about the barbershop, browse services and the gallery, and book appointments.

## Features
- Home page
- About Us page
- Services page
- Gallery page
- Bookings page (appointment request)
- Contact page (phone/email/address + social links)

## Project Structure
- `index.html` — Home
- `about.html` — About the barbershop and founder
- `services.html` — Services overview
- `gallery.html` — Image gallery
- `bookings.html` — Appointment form
- `contact.html` — Contact information and social links
- `style.css` — Shared styling for the site
- `assets/`
  - `images/` — Site images and logo
  - `css/` — Page-specific CSS (e.g., bookings)
  - `js/` — JavaScript (if used)
  - `fonts/` — Font assets (if used)

## How to Run Locally
1. Open the project folder.
2. Open `index.html` in your browser.

## Assets / Branding
- Logo: `assets/images/Logo.png`
- Background and page images are referenced from `assets/images/`.

## Notes
- The main navigation and layout styling are handled via `style.css`.
- The contact page includes Font Awesome via CDN for social icons.
